\# Student Scholarship Management Portal



\## Project Description

The Student Scholarship Management Portal is a web-based application designed to help students apply for scholarships and track their application status.



\## Objectives

\- Allow students to register and log in.

\- Enable students to submit scholarship applications.

\- Help officers, HODs, and principals review applications.

\- Allow students to track application status.



\## Technologies Used

\- HTML

\- CSS

\- JavaScript

\- Node.js

\- Express.js

\- MySQL



\## Main Modules

\- Student Registration and Login

\- Scholarship Application

\- Officer Dashboard

\- HOD Dashboard

\- Principal Dashboard

\- Application Status Tracking



\## Project Type

Web Technologies Course End Project.
